# Contributing

Flight Management Systems is proprietary software, not an open-source project. Outside contributions, copied implementations, modified distributions, and derivative works require prior written permission from Sam Samadi. Opening an issue, pull request, or discussion does not by itself grant permission or change the terms in `LICENSE`.

## Bug reports

Non-security bug reports may include:

- The affected source version or commit.
- Windows and Python versions.
- A minimal description of the steps and observed behavior.
- A small, synthetic example that does not contain private or licensed data.

Before posting, remove API keys, passwords, tokens, `.env` content, local profile data, calendar entries, route history, private callsigns, personal file paths, exported JSON, and sensitive screenshots or logs. Do not upload third-party assets unless you have permission to redistribute them.

Report security issues privately by following `SECURITY.md`; do not post vulnerability details or secrets in a public issue.

## Proposed code changes

Obtain prior written permission before preparing or submitting an outside code contribution. If permission is granted, keep the change narrowly scoped, preserve the aviation disclaimer, avoid adding secrets or personal data, and explain any new dependency, external service, data storage, or asset-licensing impact.

Acceptance, review, or discussion of a contribution does not create an open-source licence. Any special contribution terms must be agreed in writing.
